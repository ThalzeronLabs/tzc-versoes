# Segurança

Achou uma falha de segurança no Thalzeron Code? Obrigado por avisar.

- **Não abra um relato público.** Escreva para **thalzeronlabs@gmail.com**, com "Segurança" no assunto, com o passo a passo, a versão (em
  Configurações → Sobre) e o impacto que você percebeu.
- Respondemos em até 5 dias úteis e avisamos quando a correção sair.
- Cada versão do Thalzeron Code tem assinatura digital: o app só instala uma atualização cuja assinatura confere.
