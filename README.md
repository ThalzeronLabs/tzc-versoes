# Thalzeron Code

O agente de IA da Thalzeron para Windows: ele planeja, programa, testa e prova o trabalho, com o modelo que você escolher, no seu PC ou na nuvem.

Este repositório guarda os instaladores oficiais. Cada versão traz o instalador e os arquivos que o app instalado usa para se atualizar sozinho, sempre com a assinatura conferida antes de instalar.

**Baixe pela página oficial:** https://code.thalzeron.com
